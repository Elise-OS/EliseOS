# Security policy

Please do not disclose vulnerabilities in a public issue. Report them privately to the maintainers through the security reporting facility of the official Élise OS repository.

Élise OS processes sensitive household routine data. Security fixes for authentication bypass, secret exposure, command injection, data exfiltration, unsafe update behavior, or misleading reassurance are treated as urgent.

The V0 encrypts exported backups but does not yet provide unattended full-disk encryption. Physical theft of the hub remains a documented risk until the appliance image milestone.
